# Changelog

Los cambios relevantes de AppWeb Clima se documentan en este archivo. El
proyecto sigue versionado semantico.

## [1.0.0] - 2026-08-02

### Incluye

- Dashboard meteorologico oscuro, responsive y accesible.
- Busqueda por ciudad, coordenadas, geolocalizacion y globo mundial.
- Pronostico horario y semanal con comparacion Best Match frente a GFS.
- Asistente animado con Gemini opcional y recomendaciones locales de respaldo.
- Globo Three.js con modo compatible animado cuando WebGL no esta disponible.
- Favoritos, recientes, borrado selectivo y preferencia de movimiento.
- API Express local y funciones serverless para Vercel.
- PWA, CI, pruebas unitarias, integracion, E2E y regresion visual.
- Documentacion de producto, arquitectura, diseno, QA, operacion y rollback.
